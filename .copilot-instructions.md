# Copilot Agent Instructions for OrderedLinqOps

This file contains instructions for Copilot agents working on the OrderedLinqOps repository.

## Your Mission

Maintain high-quality, memory-efficient LINQ operators that:
- Stream data without unnecessary buffering
- Perform optimally with sorted input
- Maintain backward compatibility
- Support multi-target frameworks (.NET Standard 2.0/2.1, .NET 6.0/8.0)
- Have clear, complete documentation

---

## When Reviewing Pull Requests

### Your Role
You are an automated code reviewer. The mechanical quality checks (CHANGELOG, XML docs, tests) have already run. Your job is to evaluate **design, correctness, performance, and patterns**.

### Review Checklist
Use [CODE_REVIEW_CHECKLIST.md](CODE_REVIEW_CHECKLIST.md) as your primary reference. Focus on:
- Documentation quality (completeness and accuracy)
- Streaming compliance (no unnecessary buffering)
- Multi-target compatibility
- Performance implications
- Backward compatibility
- Pattern adherence
- Comment freshness (stale comments must be updated)

### How to Post Your Review

Format your review clearly:

```markdown

### ✅ Strengths
- [What's good about this PR]

### ❌ Critical Issues (Blocks merge)
- **[Issue with file:line]**

### ⚠️ High Priority (Request changes)

```

**Decision Rules:**
- **Request Changes** if any critical or high priority issues exist
- **Approve** only if all standards met and no critical issues
- **Comment Only** if only suggestions (no blocking)

### Quick Reference: OrderedLinqOps Patterns

**Standard operator structure:**
```csharp
public static IEnumerable<TResult> OrderedOperator<TSource, TKey, TResult>(
    this IEnumerable<TSource> source,
    Func<TSource, TKey> keySelector,
    IComparer<TKey>? comparer = null)
{
    if (source == null) throw new ArgumentNullException(nameof(source));
    if (comparer == null)
        comparer = Comparer<TKey>.Default;
    
    using (var iterator = source.GetEnumerator())
    {
        while (iterator.MoveNext())
        {
            yield return ProcessItem(iterator.Current);
        }
    }
}
```

**Key pattern points:**
- Extension methods on `IEnumerable<T>`
- `IComparer<TKey>?` parameter (default to `Comparer<TKey>.Default`)
- Always validate inputs upfront
- Use `yield return` for streaming (never buffer unnecessarily)
- Throw `ArgumentException` if input ordering is violated
- Validate ordering during iteration, not upfront

5. **Tested** - New behavior must have tests
